## Requirements

- Plutonium T6 (Black Ops 2) installed and working
- Launched at least once so the storage folders exist
- WinRAR or 7-Zip, for your download

## Installation

1. Download `DarkEntityT6`
2. Press `Win + R`, type `%localappdata%`, and press OK.
3. Go to `Plutonium` → `storage` → `t5` → `raw` → `scripts` → `zm` Drop DarkEntityT6.gsc In
4. Launch Plutonium T6 and start a zombies game.

**Note:** The menu is host-only by default. Other players need the host to give it to them through All Players → player → Give / Take Mod Menu.
